The world has not been copied in

This is the stand-in page that holds the world's place inside the app. The world itself is a single three-megabyte page built in the design repository, and it is copied in rather than carried here.

To put the real world here, run this once at the top of the repository:

npm run world:sync -w @witness/fsv

Then build the app again. The door will open on the world instead of on this page.
