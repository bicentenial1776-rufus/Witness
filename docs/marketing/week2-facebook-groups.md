# Week 2 — Facebook groups (researched 2026-09-09, public About pages, no login)

Headline: every group whose rules are visible bans self-promotion outright. The only
viable posture is a real research story with no product mention; name Witness only
when asked, in a comment, with "full disclosure, I built it." Only Genealogy and AI
treats tools as on-topic. Join with Rufus's real profile, reasonably public (locked
profiles get rejected). Comment helpfully ~2 weeks before the first story post.

## Considered and rejected

- Technology for Genealogy (23.6K) — no self-promotion AND ~2 posts/mo, dormant.
- Mac Genealogy (1.4K) — allows software talk but 0 posts last month.
- Genealogy! Just Ask! (63.6K) — "no preferring one company over another."
- Généalogie Acadienne / Acadian Genealogy (6.2K, public) — 12 posts/mo, rules not visible; #4 is better.
- Acadian & French-Canadian Genealogy & History (7.5K) — single admin must pre-approve anything promotional; DM the admin later only if #4 works.
- Cajun French Virtual Table Française (68.4K) — culture/language, not genealogy; hostile to "masked" content.
- GAA Genealogy Addicts Anonymous (17.4K), Genealogy Addicts UK & Worldwide (19.5K), Genealogy (genealogyone, 34K) — smaller/off-target/rules hidden.
- Family Tree Maker Support 24*7 (10.3K, public) — support-seller pattern.
- "Civil War Ancestors" / "Union Civil War Descendants" — no such groups; SUVCW presences are Pages. USCT Descendants is real but scoped to USCT.
- GEDCOM-specific groups — none exist (hits were GEDmatch/DNAGedcom).

## Playbook

1. This week: request to join #1–#8 (answer screening questions honestly: "hobbyist with a 5,600-person tree; I also build genealogy software").
2. Weeks 2–3: comment helpfully; no posts.
3. From week 3: one story per group per month, from week2-reddit-drafts.md material, adapted per group. No links in bodies. UTM links live in the profile bio and DMs only.
4. #1 is the one place to post as a builder openly.
